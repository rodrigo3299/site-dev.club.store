# 🛍️ DevClub Store

Projeto de loja virtual desenvolvido com HTML, CSS e JavaScript puro, com foco em desenvolvimento front-end, responsividade e manipulação do DOM.

## 🚀 Funcionalidades

- Carrossel automático de produtos
- Navegação por botões
- Indicador de produtos
- Header dinâmico ao rolar a página
- Formulário interativo
- Layout responsivo

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Praticar conceitos de desenvolvimento front-end, manipulação do DOM, eventos, responsividade e organização de código.
